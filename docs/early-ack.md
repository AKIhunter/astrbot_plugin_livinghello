# 垫场句轮换

群聊 @ 机器人或命中唤醒词后，主回复生成较慢时会先发一句垫场。句库内置 20 句短语，如「我看看」「嗯我想想」「等我一下」「让我捋捋」，选句不调用模型。

`main.py` 中的 `EARLY_ACK_TEXTS` 保存硬编码句库，`_early_ack_text(group_key)` 按会话记录下一句的位置。同群的 @ 和唤醒词共用同一个轮换位置，用完 20 句后回到第一句。各群及启用本功能的私聊分别轮换。位置只存在内存中，重载插件后从第一句开始。

配置 `reply_early_ack_texts` 留空、仅有「我看看」或与旧版默认三句或十二句完全相同时，运行时自动使用新句库，原配置文件无需迁移。其他自定义文案继续优先使用，并采用相同的逐次轮换方式；列表和 `|` 分隔字符串均兼容。

`_early_ack_worker` 通过发送前的检查后才选择文案。被取消、已完成、被拦截或过期的请求不会消耗轮换位置；发送尝试失败时位置已经推进，后续请求继续使用下一句。

本次只调整句库和选句方式。发送延迟、每群冷却、每条请求最多垫一次，以及垫场进入上下文的现有逻辑继续生效。该句库也用于原本已支持垫场的其他回复入口。

## 配置与触发范围

在 AstrBot 的 LivingHello 插件配置中设置：

| 参数 | 默认值 | 用法 |
| --- | --- | --- |
| `reply_early_ack_texts` | 20 句内置文案 | 每行一条；留空、仅有「我看看」或仍是旧版默认句库时使用内置文案 |
| `reply_early_ack_seconds` | `20` | 已进入回复流程但超过这段时间仍未完成时垫一句；设 `0` 关闭 |
| `reply_early_ack_cooldown_seconds` | `600` | 同群两次垫场的最小间隔，单位为秒 |
| `apply_to_private` | `false` | 开启后私聊也适用；关闭时私聊不使用本插件垫场 |

灰名单群明确 @ bot 或名字唤醒、普通群 @ bot 或名字唤醒，以及自主参与判定通过后的回复共用这套句库。固定文案模式下的纯空 @ 直接回复固定文案，不进入模型垫场流程。
