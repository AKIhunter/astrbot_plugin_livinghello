# 功能异常统一私聊

适用2.9.1。模型技术失败通过QQ私聊提醒指定管理员，通知本身不终止普通回复。
图片/语音理解失败保留已完成的文字和OCR，并明确标注未读内容；生图失败按受控类别说明。

接收人优先使用 `outage_notify_admin_qq`，留空则使用 AstrBot 全局管理员中的有效 QQ。提醒受 `classifier_outage_recovery_enabled`、对应 `outage_watch_*` 和既有提醒间隔限制。通知只含纯文本、归一化原因、来源和请求/消息编号，不带原群引用、艾特、异常原文或密钥。

当前版本在模型调用失败时通过 `report_model_fault` 异步私聊管理员；通知开关关闭或未配置管理员时不外发。媒体理解失败会保留已完成的文字和 OCR，并明确标注未读取内容，继续按回复有效期处理。通知不代表终止整轮回复。

通知关闭、管理员缺失、限频或私聊失败时仅留痕，不回退到群里。
撤回、新消息顶替和有效期守卫独立决定是否停止尚未发送的气泡，已发气泡不自动撤回。

预算裁剪、图片张数/调用次数上限、策略取消和每日生图额度用尽沿用原行为；
判定失败后成功兜底仍可回复。普通文本不会因“加载失败”等字词被拦截。
旧终止式测试草稿已归档，当前降级与提醒由test_media_fault_degradation.py验证。

模型与发送均使用替身，离线通过不代表真实私聊已实测；历史来源统一见[更新日志](../CHANGELOG.md)。
