# 生图失败只发送一次普通说明

`ImageSettings._notify_image_failure` 先发送一条受控失败说明。内容被拒绝且不能自动改词时，把调整或取消的提问放在同一条消息里；发送受理后再保存通知标记并交接待办。`adjustment_asked`只在这条消息实际包含问句时为真，设置错误等其他失败不记为已问。灰名单群或其他发送守卫拒绝时保持静默。

明确内容拒绝先执行既有有限重试；LE承诺任务的未知结果停止内部重发。
交接只记录后续状态，不追加“已记下”的第二条文字。
HTTP 502、超时等最终未知状态仍需核对，不能由模型另开一次重画，也不代表图片已经发送。

同一事件重复或并发进入通知入口，仍由通知尝试标记限制为一次。发送显式拒收、抛出异常或被发送计划拦截时，不交接，也不自动重复发送。

管理员模型故障提醒属于独立通知。管理员恰好是本次请求用户时，该提醒仍可能出现在同一私聊中。

回归测试位于 `tests/test_image_failure_contract.py`，覆盖实际后台 502 路径、六类失败的待办交接、重复调用及发送未受理。模型与平台发送均打桩，不调用收费服务。
