# 2.7.11 使用与边界说明

在插件控制台的提示词设置中选择预置，编辑后保存；重置恢复所选预置的默认文本。AstrBot 插件配置页各开关的说明指向控制台，并说明开关实际效果。

共享契约为 `livinghello.shared-prompts.v1`，完整编辑衔接使用 LivingEmotion 0.4.2。LivingHello 不要求安装 LivingEmotion；双方同时运行时沿用公开接口，不读取对方配置文件。

升级保留原有配置、自定义文本和分段设置。新字段缺少时由默认值补齐；独立注入开关关闭时对应内容不进入请求。媒体失败继续尝试文字降级，模型故障通知与普通回复独立处理。未实现旧终止式故障通知契约，不能把跳过用例当作该功能验收。

缓存键包括生效模型配置，配置变化不会沿用旧模型结果。纯技术正文仍保留列表、代码和长结构；私聊过时未发送回复仍遵守既有水位窗口。
