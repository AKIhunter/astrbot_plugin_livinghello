# 工具前后回复去重

工具调用可能让模型在同一轮中生成多份正文。宿主缓冲合并这些正文时，会把重复内容一起送到分段流程。

## 生成规则

有可用工具时，LH按模块ID装配一份请求局部规则：需要工具的回答先调用工具，工具返回后再给完整正文；工具调用前和调用之间不写聊天正文。已经说过的句段只补新增内容，失败简短说明，生图继续使用专用的短承接规则。

规则不修改手写提示词或关闭开关，也不写入持久聊天历史；没有可用工具时不添加。没有新增模型调用或重试。

## 合并规则

LH管理的非流式回复在分段前比较相邻模型正文。只删除更早正文中已出现的完全相同段落或以「。！？!?」结束的完整句子；保留第一份正文及后续新增、改写内容。

例如前一份是「设置已确认。」，后一份是「设置已确认。新增功能已开启。」，最终保留「设置已确认。」和「新增功能已开启。」。

不做相似度整篇裁剪。单份正文内部的有意重复保留；代码、表格、列表、引用、括号、链接、路径、JSON和超出现有字符清理预算的正文保守保留。不跨媒体位置或轮次比较，不改变媒体顺序。没有重复时沿用原拼接方式；流式token始终按原字拼接。

此功能随LH原生分段管理流程执行，不新增配置项。原生宿主自行管理的回复和非模型消息不接入该去重步骤；关闭气泡拆分时，LH管理的正文仍先去重。

## 费用与验证边界

源头规则旨在避免模型再次生成同样内容，但是否遵循由真实模型决定。新增规则为107字符，输入token开销和净费用变化需要实际用量确认。发送前去重不能退还已经生成的token。

`tests/test_reply_merge.py` 用合成样例覆盖新增内容、完整重复、多工具步骤、媒体与结构化内容、流式、分段关闭、最大段数、轮次隔离和提示词只装配一份。真实宿主合并函数的回放需要显式提供包含该函数的宿主源码；缺少该扩展时该项跳过，其他用例继续。离线通过不代表真实模型已节省费用。
