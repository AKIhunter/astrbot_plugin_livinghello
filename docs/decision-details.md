# 判断详情与复验

在“运行概览”或记录查询中点击“查看详情”，先查看判断结果和五个主节点：接收消息、判断是否参与、生成回复、执行工具、发送结果。

- **请求标识、监听与功能明细**：展开后查看会话 ID、消息 ID，以及各功能的状态、耗时、调用次数、结果原因和最近一次采集时间。工具、发送等节点可在节点内展开多次事件。历史记录缺少时间时显示“时间未采集”。监听覆盖默认收起，显示正常项数，可手动展开查看各监听状态。
- **判定依据与模型上下文**：查看模型调用过程和分数修正（如有）。参考流水、当前消息、引用内容、机器人上一句和会话背景按本次保存的输入展示；当前消息只展示一次。
- **判定原始输入与输出**：展示日志保存的请求文本和判定模型返回。这里不含系统规则、图片本体或每次重试的完整请求；超过日志保留上限时可能截断。规则过滤或显式唤醒未调用判定模型时，直接显示未调用。
- **复制复验内容**：按钮常显，复制用于试跑的消息资料，保留文字、空格和结构。旧记录无法分段时复制该条日志留存的全文。
- **查看判定规则**：一步跳到“流程与试跑”的只读规则区。文字判断和识图判断分别展示固定开头规则、结尾要求；这一区域来自当前版本代码，不是历史请求未保存的系统规则快照。

运行中的追踪每 2 秒自动更新，保留展开状态和滚动位置；请求结束或关闭弹窗后停止。读取短暂失败先重试一次，随后按自动刷新周期重试，避免慢桥通道造成一次失败就不再更新。

最终投递只有明确的发送完成原因才会收尾为成功。请求结束但其他节点缺少结束回调时显示“结束状态未采集”，不把等待状态当作成功，也不据此推断进程退出或服务重启。取消、静默分别显示取消或跳过；原始事件仍保留当时采集的状态。历史记录的修正只发生在读取视图，不回写数据库。

将复验内容粘贴到“文字试跑”后不会自动调用模型。点击“判定一下”才会产生判定 API 用量；试跑使用当前已保存配置和当前规则，不发送聊天消息，因此不保证重现旧版本或旧配置下的同一结论。

本次改动没有新增配置或存量迁移。离线错误响应替身修复只影响测试进程，不改变生产错误响应接口。
