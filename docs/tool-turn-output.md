# 工具回复与 QQ 私聊即时生图

LivingHello 只绑定本轮主请求对应的 AstrBot runner 实例。QQ 私聊、非流式、`full` 工具模式下，模型响应同时包含工具调用和聊天文字时，只去掉那一步的 `Plain` 和 `completion_text`。工具 ID、参数、签名、用量、非文字组件和工具结果仍由宿主处理。纯聊天结果、错误响应、显式工具投递、流式与其他会话沿用原链路。

即时单图的首个模型步骤里，工具说明额外提供 `immediate` 与 `reply`。例如用户接着上一轮说「拍给我看看宝贝」，主模型结合本轮和上文确认只要现在收一张图时，填 `immediate: true`，并同时给出 `reply`（对人说的一句承接）与 `prompt`（给生图模型的画面描述）。`immediate` 和 `reply` 在执行前剥离，工具参数和工具历史只保留业务字段。工具说明只在本轮首个步骤扩展，不改共享工具或人设配置。若之前保存的是逐字一致的内置生图提示词，运行时采用新预设；保留手写文案和开关状态。

QQ 私聊在提供生图工具前先查共享额度。已用完或剩余位置被临时占用时，本轮不提供生图工具，并把对应事实交给主模型；只有用户本轮确实要出图才按人设婉拒，其他问题仍正常答。`即时单图` 指本轮只要一张现在发出的图，无其他问题、工具或定时安排；图片仍可后台生成。

首个有效模型结果明确标记 `immediate: true`、且只调用一次普通生图工具时，程序按缺项补写：

| 当前结果 | 后续动作 |
| --- | --- |
| `prompt` 和 `reply` 都有效 | 执行一次工具预检。通过就使用该承接语，主模型无需再请求。 |
| 画面描述或参考图开关无效 | 用第一次请求的上下文只重写生图参数。保留合格的 `reply` 和已明确的参考图开关，得到有效参数后才执行工具。 |
| 工具已预检通过，`reply` 缺失或无效 | 校对工具调用 ID、参数及当前作业的实际回执。保留有效参数与已准备作业，仅给模型最近四条纯文本对话和简短人设摘要，只补 `reply`。不传工具、工具结果、附件或画面描述。 |
| 两项都无效 | 先补生图参数，预检通过后再用剩余次数补 `reply`。 |
| 真实预检拒绝或失败 | 丢弃成功承接语，由同一主模型只写一句符合真实原因的回复。缺少或读不到参考图时请用户发图；其他情况按人设说明，不请求生图、不建立续跑事项。 |

首个有效模型结果后最多追加两次补写，参数、承接语和失败回复共用预算。每次仅请求同一成功 Provider 和模型，且只允许一轮底层请求（宿主 Provider 支持时），等待最多 15 秒。第 2 次正文仍不合格、第 3 次继续补正文；第 3 次仍不合格，结束本轮，不发成功承接语、不请求生图。有新的消息顶替或预检回执不能匹配本轮时，也不放行图片。补写期间配置或额度变化，发送成功承接语前再核对留位；新发现的失败只能使用剩余补写次数。首家模型的失败切换仍走原规则，计入实际请求数。

混合请求、显式 `immediate: false`、多工具、待办续跑、合并输入、TTS、可见工具提示、未经适配的宿主分段或前缀、不能读取 QQ 回执的宿主时，继续走原工具与模型收尾。为兼容只输出合格 `reply` 的首次模型结果，省略 `immediate` 且有合格候选时仍可走即时收尾；该候选遇到预检失败时仍须改写为失败回复。省略标记且没有合格 `reply` 时，不启动补写。

预检通过后立即开始生图，同时将承接语送入原回复管线，保留常规文字清理并作为一条气泡。只有这条最终回复的 OneBot 私聊动作返回非零 `message_id`，图片或生图失败提示才能发送。无回执、文字被替换、拒收或轮次被顶替时，取消待发图片；同文案的其他消息和发送回调本身不能放行图片。快图等回执最多 185 秒，宿主结束本轮会提前清理。已生成但未投递记为 `cancelled`，上游请求进行中被取消记为 `unknown`。若上游已收到请求，文字投递失败仍可能产生费用。

文字回执只放行图片。共享额度要等到图片自己的发送回执才增加；同一张图只计一次。详见[图片回执与原事项结算](image-delivery-receipts.md)。

其他工具如需接入，从 `reply/guard_turn_output.py` 的 `TOOL_REPLIES` 注册。回复层负责扩展请求内工具说明、剥离候选、校验唯一工具调用及结果归属，并认领最终气泡和平台回执。工具适配器负责声明适用条件、根据工具结果选择正文、放行或取消自己的后台任务。需要等待结果才能回答的工具保留原工具循环。

排查时看 `turn_output_repair` 的字段、结果和调用次数，以及 `turn_output` 的 `local_tool_*`、`image_prompt_unavailable`、`image_reply_unavailable`、`onebot_text_confirmed` 和 `onebot_text_receipt_timeout`；图片是否交付以图片回执为准。`tests/test_turn_output.py` 使用真实 AstrBot runner、QQ 适配器和本地 SQLite 回执，聊天模型、生图上游和 OneBot 动作用离线替身。只安装宿主替身的全量回归会跳过该文件；验收图文顺序时要另用完整宿主回放。

热重载仍依赖先阻断入口并确认在途请求清零。未完成排空时，不应替换正在处理的生图任务。
