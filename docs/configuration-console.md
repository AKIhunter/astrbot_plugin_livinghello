# LH 配置页面与问号说明

回复配置使用一套导航：回复行为、功能耦合、原生配置、称呼与私聊、
内容理解、黑白灰名单、断线恢复、提示词注入。原生语音、文本转图、
AI 生图和分段开关直接展示；只有高级数值和正则参数折叠。

## 说明来源

`pages/guard/index.html` 中的 `SWITCH_HELP` 维护 LH 开关的开启、关闭和设置位置。
具体作用和示例继续使用后端 `fieldHelp` 与已有 `FIELD_HELP`。
`NATIVE_HELP` 维护原生分段、语音、文本转图及生图开关的说明；
模型等参数的作用来自原生接口返回的字段定义。
提示词开关的适用范围来自后端提示词目录。

问号与参数手册共用说明。每个开关说明包含作用、开启后、关闭后、
去哪设置；参数说明提供作用、设置位置及已有示例。
问号用键盘可打开，关闭后返回原焦点。

上游轮转按优先级逐个短超时尝试，并非并发。
撤回保护覆盖等待、生成和未发气泡，并非仅在碎片等待窗口内生效。
这些改动只修正文案，不更改相关运行规则。

## 自动刷新与保存

页面每 15 秒完成一轮状态、原生分段、原生模型设置及生图配置读回；
上一轮结束后才安排下一轮，避免请求叠加。读取模型列表不调用模型生成。
原生配置没有变化时不重建控件。

LH 普通配置只更新未编辑、未聚焦的字段。原生区域有草稿或焦点时保留
控件与旧保存版本；检测到外部更改会提示，后端继续按修订号检查保存冲突。
原生读回响应如果晚于保存返回，以读回启动时的版本判断并丢弃旧响应。
弹窗打开时暂停刷新控件。

保存中、成功、失败及部分成功结果均显示在底部保存区域。
未成功保存的草稿保留，放弃更改只撤销当前草稿。
原生数值输入范围与保存校验一致，不改变默认值、schema 或运行时配置。

## 验证

`tests/ui/config-help.test.mjs` 检查开关问号覆盖、外部原生变更自动读回、
草稿与焦点保护。已有页面、耦合、保存延迟测试继续覆盖
320/390/1280 宽度、浅深主题、键盘、读写错误和部分保存。

运行 UI 测试时用 `PLAYWRIGHT_MODULE` 指定现有 Playwright 安装位置。
测试桥是隔离夹具，原生 AstrBot 环境的加载与保存另行验收，
两者不能作为同一层验证。测试不调用付费模型。
