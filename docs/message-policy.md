# 黑白灰名单

在“回复与私聊”点击第八个跳转入口“黑白灰名单”，分别填写各类 QQ 号和 QQ 群号。六项默认空，不影响升级前行为。名单先于参与判断、私聊直通、原生 @、称呼唤醒及观察模式生效。

## 规则优先级

| 顺序 | 条件 | 读取消息 | 参与判定 | 回复资格 |
| --- | --- | --- | --- | --- |
| 1 | QQ 或群号命中黑名单 | 不消费正文和媒体 | 不调用 | 无 |
| 2 | 白名单已启用，QQ和群号均未命中 | 保留基础聊天背景 | 不调用 | 无，@也不例外 |
| 3 | QQ或群号命中灰名单，没有明确唤醒 | 保留基础聊天背景 | 不调用 | 无 |
| 4 | 灰名单原生@机器人或称呼唤醒 | 可以读取 | 跳过参与小模型 | 有，仍受撤回、作息、时效等约束 |
| 5 | 其他允许消息 | 原行为 | 原行为 | 按原参与规则处理 |

任一白名单非空即启用限制；两类白名单都清空并保存后解除。QQ号或群号任一白名单命中即可取得资格。名单内不保证每条回复，模型正常静默和宿主其他约束仍生效。

灰名单唤醒只认当前顶层原生 @ 当前机器人，或无其他人 @ 且正文以已配置机器人称呼开头。@他人、@全体、引用/转发内的 @ 或称呼、自己发出的消息都不算。私聊普通文字同样静默，以机器人称呼开头可以唤醒。同用户、同会话的有效碎片批次可继承真实唤醒；撤回、取消、过期或名单变更使旧批次失效。

## 跨类型示例

| 配置组合 | 实际结果 |
| --- | --- |
| 白名单群中的黑名单QQ | 不读、不响应 |
| 白名单QQ发到黑名单群 | 不读、不响应 |
| 白名单群中的灰名单QQ | 普通消息只读；明确唤醒才有资格 |
| 灰名单群中的白名单QQ | 同样需要明确唤醒 |
| 灰名单QQ未命中任何已启用白名单 | 即使明确唤醒仍只读 |

平台类型来自实际平台元信息，支持 `aiocqhttp / onebot / onebot_v11 / qq`。UMO第一段是平台实例ID，不能单凭它或裸数字判定QQ。其他已确认平台保持原行为；QQ关键身份缺失且无法排除黑名单时保守拒绝。

## 填写、校验和移动

支持换行、空白、中英文逗号、顿号和分号。全角数字转半角，前导零去除，重复项保留首次出现次序。每项最多500个号码，六项原始输入合计最多128 KiB。号码为1–20位正整数；昵称、URL、小数、科学计数法、零、布尔和嵌套对象均拒绝。长号码按字符串处理，不丢精度。

QQ三名单两两互斥，群号三名单也两两互斥；QQ与群号数字相同不冲突。错误会标在双方字段旁，保留原始草稿。移动时从原名单删除、加入目标名单，再统一保存。不会自动搬移、删错号或部分保存。

“校验名单”只验证，不保存、不读取聊天、不调用模型。统一保存先校验名单，再开始原生子配置保存；服务端在写入锁内再次验证完整合并候选。六项一起提交，空字段显式清空。名单修订不匹配返回409，保留草稿；放弃草稿后可“重新读取名单”。普通其他参数继续兼容原保存接口，各配置域仍分别返回结果。

磁盘失败恢复本次字段和原策略快照。手动配置非法时有旧有效快照则继续保护；冷启动无有效快照则阻止QQ消息消费，修正后恢复。页面显示生效修订、白名单是否启用与配套状态。

## 实时、历史和待发消息

最早消息钩子在读取正文前检查名单。黑名单不建立正文追踪、碎片、图片缓存或恢复事件，仅记录无正文拦截计数。只读消息只保存基础文本，不调用图片、语音或摘要模型；LivingEmotion基础归档后停止响应流程。

引用和转发按结构化原作者、实际群来源逐层核验。原作者被屏蔽时不拉取；作者未知时必要的平台返回包只用于核验元信息，通过后才处理正文。无法核验的引用使用占位提示。旧扁平引用、转发和机器人摘要不能拆来源时整体跳过；不靠字符串删词或模型脱敏。

LivingEmotion原始聊天查询在SELECT正文前按绑定参数过滤黑名单，并在需要时限定完整UMO。灰名单/白名单外可作背景，不能成为普通回复候选。名单变更使旧媒体、碎片和摘要修订失效；生成中和每条待发气泡在下一阶段或发送前复核。已经发送的消息不会追溯撤销。

旧数据库记录不删除，被过滤旧消息不标为已读。既有长期事实、记忆、向量、索引和日记继续保留。这里的“不读取”指插件不消费或持久化屏蔽消息，不能阻止平台适配器接收数据包，也不能撤回屏蔽前已送给模型的资料。

## LivingEmotion配套

LivingHello是唯一可编辑规则来源，提供 `livinghello.message-policy.v1` 快照和判断接口。LivingEmotion声明 `congling.message-policy.v1`，动态读取激活实例，不读取对方磁盘配置。

激活的LivingEmotion缺少历史过滤契约时，非空名单保存会被拒绝并提示更新。独立使用LivingEmotion且从未接入限制时保持原行为；接入限制后接口异常或实例暂时消失则保守拒绝QQ处理。热重载沿用宿主Context上的限制状态，有效空名单快照才解除保护，不另存第二份名单。

主动群发需要实际允许的群目的地；只填写白名单QQ不能授权无人明确唤醒的群主动消息。断线恢复和爬楼同样复核候选及修订；名单拒绝归为 `no_reply`，原未知发送结果保持未知，不重放。

## 人工复验

在最近判定详情复制“中间输入”，粘贴到“文字试跑”，再手动点击“判定一下”。结构化资料还原当前消息、上下文、上一句及合法来源。普通文字无来源时明确提示“未模拟名单来源”。

有合法来源先模拟当前已保存名单。黑名单、白名单外、灰名单未唤醒不调用参与模型；灰名单明确唤醒展示直通。此类结果显示未评分，不伪造0分。试跑不发送消息、写入生产统计、预算、碎片、冷却、断线事件或用户记忆。

完整操作和输入预算见[使用指南](usage.md#查看流程与文字试跑)，规则与模型边界见[判断逻辑](decision-logic.md)。
