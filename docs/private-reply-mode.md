# 私聊是否复用回复方式

入口：LivingHello 控制台 → 回复与私聊 → 回复方式 → 私聊是否复用。

配置键 `expression_private_reuse`，布尔值，默认 `false`。勾选或取消后点击“保存参数”生效。

关闭时，私聊正文直接发送，不自动引用当前用户消息，也不沿用本卡片的 Emoji 与颜文字清理。插件仍管理事件的发送边界，避免从绫或宿主重新插入当前消息的引用。普通回复、流式回复，以及原生模型失败提示所带的当前消息引用都在实际发送前移除。

开启时，私聊按“引用当前消息”和“清理文本 Emoji 和颜文字”开关处理；当前发送者的 @ 仍仅用于群聊。群聊不受该私聊开关影响。

本开关只控制“回复方式”卡片。分段、回复节奏、碎片等待、撤回保护、黑白灰名单及输入中的历史引用理解继续遵循各自配置。正文里明确指向其他历史消息的引用保留。

实现位置：`reply/guard_expression.py` 根据会话判断是否复用，`reply/guard_reply_delivery.py` 在最终发送和流式合并边界应用该判断。配置由宿主 Schema 派生到控制台的可保存字段，无需修改平台全局引用开关。
